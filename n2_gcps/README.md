# n2_gcps

É um app tradicional do flutter que ao clicar no botão, o total de cliques é adicionado a contagem

## Rodando

Você pode baixar ou clonar o repositório na sua maquina e executar o app em seu emulador.

## Por quê do app

É utilizado o programa padrão de uma aplicação Flutter, pois o objetivo é apenas demonstrar a utilização de conceitos de CI/CD
